# 📊 Business Data Assistant

A professional data analysis tool built with Python & Streamlit.
Upload any CSV or Excel file and get instant cleaning, exploration,
visualizations and downloadable reports.

## Features
- Upload CSV or Excel files
- Smart data cleaning (duplicates, missing values, whitespace)
- Interactive data explorer with statistics
- 6 chart types (Bar, Line, Scatter, Pie, Box, Heatmap)
- Full downloadable report in CSV + Excel
- Action history log

## Setup
pip install -r requirements.txt

## Run
streamlit run business_assistant.py

## Tech Stack
Python · Streamlit · Pandas · Plotly · xlsxwriter
